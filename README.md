# ISLASPHI

Original project title: IslasPhi

Student name: Mark Aeron Palileo

Website category: Travel and cultural guide for the Philippines

## Project description
IslasPhi is a responsive single-page website built with HTML, CSS, and JavaScript to showcase the culture, destinations, food, and travel planning information across the Philippines. The project includes five main sections: home, region explorer, trip planner, saved spots, and community travel logs.

## Main features
- Home page with hero section and island-cluster navigation
- Explore view for the 18 Philippine regions with search and filtering
- Trip planner with budget estimation and itinerary generation
- Saved destination bookmarks using browser local storage
- Community reviews submission form with validation
- Responsive layout for desktop, tablet, and mobile screens

## Technologies used
- HTML5
- CSS3
- JavaScript (ES Modules)
- Bootstrap 5 (CDN)
- Node.js + Express
- LocalStorage for persistent data
